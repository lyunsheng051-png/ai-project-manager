## 验证时修复的问题

- Vue 响应式配置包含 Proxy，不能直接传入 Electron IPC；接口层转换为普通 JSON 数据后发送。
- Windows 的 `npm` 在 PowerShell 中可能匹配受执行策略限制的 `npm.ps1`；服务和终端默认使用 `cmd.exe`，不修改系统策略。
- 结束 Windows 进程树后立即再次关闭 PTY，会触发 node-pty 对已退出进程的 AttachConsole 错误；改为先等待实际退出事件。
- 停止或移除项目后，尚在检查目录与端口的异步启动可能继续执行；通过取消代次在创建进程前再次检查。
- 干净工作区的 Git 命令输出必须保持空字符串，避免把成功提示误当作变更记录。
- 正常客户端启动不再传入隐藏窗口参数；加载完成后主动显示窗口，二次启动时显示和聚焦现有窗口。桌面内部服务改为自动选择空闲端口，避免网页预览占用 5178 时阻止客户端启动。
- Git 状态的未跟踪文件模式由目录汇总改为逐项文件输出；变更文件列表取消分页，独立滚动并支持全选，文件路径通过 NUL 分隔的标准输入传给 Git，保留特殊文件名的字面含义。

# 桌面第一版架构

## 职责边界

Vue渲染端负责展示和交互，不能直接访问Node。sandbox和contextIsolation保持开启；preload只暴露固定请求入口和事件订阅。主进程校验请求来源、操作名称及参数后调用本地服务。

`dev:desktop` 启动器转换主进程并启动随机本机端口的 Vite 服务，然后打开 Electron；不会打开系统浏览器。正常启动清除隐藏测试标志，界面加载后主动显示和聚焦窗口。桌面进程通过父子 IPC 报告窗口就绪；退出及 Ctrl+C 沿用主进程清理流程。网页预览独立使用固定的 5178 端口。

安装版通过 `npm run package:win` 生成，使用 `aipm://app/` 标准安全来源读取随包提供的界面资源，不启动开发服务器。资源处理限制在应用 `renderer/` 目录内；开发模式与安装模式共享主进程服务及 preload 白名单。终端模块、原生 DLL 和 Worker 保留为真实文件，发行包不使用 ASAR。Inno Setup 负责当前用户安装、快捷方式与卸载；构建步骤见 [Windows 打包说明](packaging.md)。

`core/desktop-lifecycle.ts` 管理托盘和退出流程。正常关闭窗口仅隐藏，不销毁 BrowserWindow 或卸载页面，保留 PTY 会话、草稿和编辑器历史；点击托盘图标或单实例再次启动可恢复。托盘菜单及设置页 `app:quit` 提供完全退出入口：先确认运行中的服务，再经过页面未保存检查，只有窗口实际关闭后才执行进程清理；取消任意确认都继续保留会话。托盘创建失败时恢复正常关闭流程，避免窗口隐藏后无法找回。隐藏自动化实例不创建系统托盘；Windows 会话结束不转为后台隐藏。

项目存储采用应用数据目录中的JSON快照，通过串行写入及临时文件重命名保存。配置损坏时保留原文件副本并报错。扫描器有深度和目录数量上限，忽略依赖和产物目录，不跟随目录链接。

Git使用系统CLI与参数数组调用，写操作按仓库串行。工作区状态使用NUL分隔输出，避免空格和中文路径解析错误。外部程序并发操作Git时仍可能出现锁或状态冲突，此时展示Git返回的错误并允许刷新，不强行解锁。

服务和终端使用node-pty。服务保留有界输出并向界面批量发送；终端由xterm.js渲染。Windows停止流程先对登记的PTY进程运行taskkill进程树清理，再关闭PTY并等待退出事件。运行中的进程不等同于就绪服务；填写HTTP地址后单独探测。

## 启动状态

无就绪地址：启动 -> 运行中 -> 已停止/失败。

有就绪地址：启动中 -> HTTP响应 -> 已就绪。45秒内未确认则显示运行中及提示；进程退出则显示退出码。组合启动遵循配置依赖，前一服务未就绪时停止后续启动；已启动的服务保留并可统一停止。

取消组合启动、停止服务和退出应用会使未完成的启动令牌失效，避免等待路径/端口检查后继续创建新进程。服务删除前检查其他配置是否依赖它。

## 工作区布局

项目上下文使用 44px 顶栏，功能导航为 35px。Git 文件列表和差异预览各自滚动，提交说明与提交按钮固定在文件列表底部，提交历史保留分页。文件浏览左侧为不分页的目录树，根节点默认展开，子目录按需加载，保留展开状态并支持全部收起、键盘导航、失败重试和刷新；右侧保留文本预览与编辑。目录树刷新不覆盖编辑中的草稿。

Git 和文件页面至少保留 260px 的工作区域。切换页面时重新计算输出面板上限，避免在服务页拖大终端后遮住 Git 的文件和提交区域。输出面板默认高度为 220px，小窗口为 180px；已有手动设置会保留，并根据当前可用空间限制实际高度。

文件编辑通过 `files:save` 白名单接口进入主进程，重新检查项目路径边界与 UTF-8 内容。按文件串行保存，比较读取时的原内容，并通过同目录临时文件重命名替换，保留 BOM 和换行格式。发现外部修改时拒绝覆盖。未保存内容在切换文件、功能页、项目或设置页前提示；刷新和完全退出时通过卸载拦截提示，关闭到托盘时保留草稿。无法对其他进程的写入实施跨进程文件锁，应避免多个工具同时保存同一文件。

文件树和 Git 变更列表共用状态颜色：未跟踪红色、仅暂存绿色、工作区修改蓝色、冲突红色，无变化维持常规字体颜色；目录汇总子项状态，选择文件时保留状态颜色。文本文件默认进入 CodeMirror 编辑器，语法按文件类型异步载入，输入时实时更新高亮，不渲染或执行源 HTML。行号与编辑区域按可见范围渲染，保留深色代码主题。

`useFileTabs` 管理每个打开文件的原文、草稿、加载与保存状态，`FilePanel` 提供可关闭标签。同一项目在文件页、服务页和 Git 页之间切换时保留文件面板；各文件的编辑器保持独立实例，以保留撤销历史、光标和滚动位置。切换标签不保存、不清空草稿，只有 Ctrl+S 调用保存接口。关闭脏标签需要确认，切换项目或退出统一检查所有未保存文件，图片标签始终只读。

图片通过 `files:image` 读取项目内文件，检查格式、路径边界和 20 MB 大小上限，返回有明确 MIME 的 data URL，由图片元素解码。SVG 以图片模式显示，不以内联 HTML/对象方式执行。主进程的文本保存接口同样拒绝图片（包含 SVG），保证图片只读。

## 第一版限制

- 源码开发模式需要开发服务器；Windows x64 安装版随包提供编译后的界面与 Electron，不依赖开发服务器。目前未配置代码签名、自动更新及在线发布。
- Windows优先；其他平台相关分支未经同等桌面验证。
- 不提供完整IDE、语言服务、断点调试、代码补全或AI编码代理。
- 文件浏览提供轻量纯文本编辑，Markdown也以源文展示，不执行仓库HTML/脚本。支持创建空文件和目录、复制与移入回收站，并编辑 UTF-8 文件，文本大小上限 1 MB；不支持重命名文件。

顶栏分支选择器从 `refs/heads/` 加载全部本地分支，提供搜索和滚动列表，切换使用 `git switch --no-guess`，不从远端猜测并创建分支。仓库变更通过项目级状态协调：编辑器有未保存内容或正在保存、复制、删除、Git 操作时阻止切换；切换期间暂停面板交互，成功后通知目录树、文件标签、差异及历史刷新。原有分支管理窗口使用相同的协调入口。

删除经 `files:delete` 调用独立文件服务，校验真实路径、项目边界、Git 内部路径和已导入项目根目录，拒绝符号链接及联接目录；再次检查目标身份后只调用系统 `shell.trashItem`，不提供永久删除后备路径。界面统一确认目录及其子文件，列出受影响的未保存编辑；仅在回收站操作成功后移除对应标签并刷新树和 Git，失败时保留编辑内容。

新建操作经 `files:create` 白名单 IPC 调用文件服务。父目录通过 `realpath` 校验项目边界，禁止 Git 内部目录及无效、系统保留名称；文件以 `wx` 独占创建，目录以非递归 `mkdir` 创建，不覆盖已有文件、目录或符号链接。界面在目录或文件所在层级创建单个名称，不自动补建多级路径；创建成功后保留树的展开状态并刷新 Git，文件打开独立标签，目录展开并定位。右键菜单、工具栏、`Alt+Insert` 共用同一创建对话框，配色跟随主题。

文件复制由 `file-copy` 服务执行，IPC 对源数量、路径和冲突策略做校验。目标限制在已导入的项目内，源可为注册项目中的文件或用户从本机剪贴板、拖放指定的外部文件。复制前检查同名项，用户可选择保留两者或跳过；执行时仍以非递归 `mkdir` 或 `COPYFILE_EXCL` 独占创建目标，不覆盖、不合并已有目录，也不移动或删除源文件。禁止目录复制到自身或子目录，递归时跳过符号链接、联接目录及 Git 内部项；单项失败后保留已完成部分并汇总失败原因。每个项目的复制任务串行执行，树和 Git 在完成后刷新，编辑草稿保持不变。

Windows 文件剪贴板使用隐藏的 PowerShell STA 进程读取和写入 `FileDropList`，调用仅发生在用户复制、粘贴时；无常驻轮询，具有超时限制。多项路径以 JSON 标准输入传递，命令文本只包含固定脚本，不拼接路径，也不随选择数量增加命令行长度。拖入文件通过 preload 中的 `webUtils.getPathForFile` 获取原始本机路径，不使用已移除的 `File.path`；浏览器预览不读取本机文件路径。其他平台使用文件 URI 剪贴板格式。

文件树选区由独立组合式逻辑管理，与当前编辑标签、键盘焦点分开维护。Ctrl 点击切换单项，Shift 按可见树行和锚点计算区间，Ctrl+Shift 追加区间；刷新时保留仍存在的选择，收起目录后清理不可见子项。复制、拖动和删除先合并父子重复项；文件剪贴板一次写入全部路径，内部拖动携带项目内路径数组。批量删除统一展示回收站确认和未保存编辑列表，逐项执行，仅关闭成功删除项的标签；失败项保留并可重试。
- 只发现常见入口，描述文件、环境管理器和复杂工作区仍需用户核对。
- 配置文件存储尚未加入操作系统密钥库，环境变量按明文处理。
- 不支持应用被强制结束后的跨重启进程恢复，也不自动接管外部服务。
